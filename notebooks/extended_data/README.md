# Extended Data notebooks

These notebooks will contain diagnostics, sensitivity analyses and robustness
checks that support, but do not interrupt, the main manuscript workflow.

Available notebooks:

- `ED01_population_scene_and_arrival.ipynb`
- `ED02_fragility_sensitivity.ipynb` — urban-depth and proximity-based shared-loss
  diagnostics, neighborhood-density comparison and fragility model-form sensitivity
- `ED03_construction_sensitivity.ipynb`
- `ED04_defense_sensitivity.ipynb`
- `ED05_sen_sensitivity.ipynb`

Each Extended Data result must identify the main estimate or modeling decision
that it evaluates.

ED04 includes the full defense sensitivity to three Eaton progression maps.
Palisades timing and all non-progression analysis choices are held fixed.
