# Main analysis notebooks

The notebooks in this directory will follow the order of the manuscript and
generate the main-text estimates, tables and figures.

Each notebook must:

1. state the manuscript subsection and figure it reproduces;
2. define and print its analysis population;
3. run from a clean kernel without hidden state;
4. save a machine-readable headline-results table;
5. save source data for every figure panel; and
6. record package versions and random seeds.

Exploratory analyses and robustness checks belong in `extended_data/`.
